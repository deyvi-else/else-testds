# Test design system

Front-end assets translated from the
[Test design system Figma file](https://www.figma.com/design/kDoLf0s6Vdeg8dS8cgi1ro/Test-design-system).
Figma is the source of truth.

Use the **Theme** toggle in the toolbar to switch between light and dark.

**Foundations** documents the design tokens. The pages are generated from the token JSON exported from Figma, and everything on them is drawn with the CSS custom properties in `tokens.css`.

Components will appear here once they are built from Figma.
